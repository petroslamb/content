# 05. Final Shortlist

Final question:

> Which papers from the last 3 months look most important for multi-agent systems?

Final answer:

## 1. `2602.01848` ROMA: Recursive Open Meta-Agent Framework for Long-Horizon Multi-Agent Systems

ROMA looks like the strongest direct architecture paper in the set. It attacks the practical long-horizon systems problem with a reusable recursive decomposition-and-aggregation pattern, and it already shows unusually strong GitHub traction for such a recent paper. It ranks first because it combines technical generality, apparent empirical strength, and a credible path to broader adoption.

Signals behind inclusion
- Feed prominence on the agentic GitHub surface
- Strong practical architecture contribution
- Likely lasting relevance as a reusable build pattern

## 2. `2601.04748` When Single-Agent with Skills Replace Multi-Agent Systems and When They Fail

This paper earns a top spot because it does not merely improve multi-agent systems; it questions when they are needed at all. That makes it one of the most conceptually important papers in the set. The efficiency gains and failure-mode analysis make it more than a philosophical critique: it gives the field a concrete framework for deciding when to use multi-agent structure and when to collapse it into a skill-based single agent.

Signals behind inclusion
- Direct multi-agent framing from search
- Strong conceptual novelty
- High likely citation value as a field-reframing paper

## 3. `2603.00349` EmCoop: A Framework and Benchmark for Embodied Cooperation Among LLM Agents

EmCoop ranks highly because benchmarks and evaluation frameworks can shape a field for a long time when they expose the right gaps. This paper looks like one of the more credible recent attempts to make embodied multi-agent cooperation measurable rather than anecdotal. It is less about one clever orchestration trick and more about giving the area a durable evaluation surface.

Signals behind inclusion
- Strong GitHub-ranked visibility on the agentic feed
- Clear embodied multi-agent benchmark focus
- Potential long-run importance as evaluation infrastructure

## 4. `2602.15382` The Vision Wormhole: Latent-Space Communication in Heterogeneous Multi-Agent Systems

This is the highest-novelty mechanism paper in the shortlist. It proposes latent-space communication for heterogeneous multi-agent systems and claims a better scaling profile than pairwise text-based exchange. It ranks below the top three because its adoption path is less certain, but it still looks important enough to keep because it pushes on a core systems bottleneck: inter-agent communication.

Signals behind inclusion
- Exact multi-agent search hit
- High technical novelty
- Direct relevance to heterogeneous multi-agent coordination

## 5. `2602.11865` Intelligent AI Delegation

This paper made the list because delegation is a real coordination problem as agent networks become more capable and more autonomous. It feels more framework-oriented and less technically decisive than the papers above, which is why it ranks fifth, but it still looks like one of the better recent papers on how authority, trust, and delegation should be structured in agent ecosystems.

Signals behind inclusion
- Visible in the multi-agent-learning feed
- Broad relevance to agent coordination and delegation
- Stronger multi-agent relevance than the adjacent enabling papers below

## Suggested Reading Order

1. `2601.04748` to understand the central design question: when should multi-agent systems exist at all?
2. `2602.01848` to see the strongest direct architecture answer for long-horizon multi-agent systems.
3. `2603.00349` to understand how embodied cooperation should be evaluated.
4. `2602.15382` to see a novel communication mechanism for heterogeneous agents.
5. `2602.11865` to round out the shortlist with delegation and coordination framing.

This reading order is slightly different from the final ranking because it moves from field-level framing to architecture, then evaluation, then mechanism, then governance/delegation.

## What Almost Made The List

### `2601.01885` Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents

Very strong recent agentic paper with heavy visibility, especially on the GitHub-ranked feed, but it is primarily a single-agent memory systems paper rather than a direct multi-agent contribution.

### `2602.23008` Exploratory Memory-Augmented LLM Agent via Hybrid On- and Off-Policy Optimization

Strong adjacent agent-training paper with real visibility, but still better categorized as enabling agent infrastructure than as a central multi-agent systems paper.

### `2601.14192` Toward Efficient Agents: Memory, Tool learning, and Planning

Useful survey and backgrounder on efficient agents, but not the right kind of paper to anchor a shortlist of the most important recent multi-agent contributions.
