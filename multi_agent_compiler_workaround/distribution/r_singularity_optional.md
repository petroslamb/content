## Title

I think many multi-agent systems are a transitional phase, not the end state

## Post Body

The most interesting agent paper I read this month was not interesting because it proved swarms are the future. It was interesting because it showed that many multi-agent systems can be collapsed into a single agent with skills while preserving comparable quality and cutting cost.

That does not kill the multi-agent idea. It changes the question. Instead of asking how many agents we should build, the better question is which bottleneck the extra agents are compensating for.

A lot of agent stacks seem to exist because one model struggles with routing, memory, tool confusion, and intermediate state. In that world, the swarm is often scaffolding. Useful scaffolding, sometimes necessary scaffolding, but still scaffolding.

There are still cases where multi-agent looks real: mixed-model systems, authority boundaries, embodied coordination, and deliberate exploration. But the recent literature makes it harder to treat bigger graphs as automatic progress.
