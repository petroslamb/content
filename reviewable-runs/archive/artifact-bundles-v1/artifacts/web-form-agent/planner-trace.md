# Planner Trace: Web Form Agent

## Step 1: Observe current portal state

- confirm login state
- identify reimbursement dashboard and draft-claim button

## Step 2: Gather evidence

- open booking confirmation page
- record travel amount, vendor, and receipt identifiers
- store evidence rows in the run record

## Step 3: Enter draft claim

- navigate to reimbursement form
- select travel reimbursement category
- populate amount, trip dates, and receipt references
- upload receipt package

## Step 4: Verify page state

- confirm category, amount, and attachments after upload
- re-check that auto-refresh did not reset claim type
- confirm the final page is the draft-review step, not the submitted state

## Step 5: Hold at approval gate

- present prepared submission summary
- wait for approval before clicking `Submit`
