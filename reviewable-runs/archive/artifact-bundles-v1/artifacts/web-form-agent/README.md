# Artifact Guide: Web Form Agent

Read these files in order:

1. `input-brief.md`
   The browser task, the approval boundary, and the dynamic page risks.
2. `planner-trace.md`
   The observe -> summarize -> act -> verify sequence.
3. `state-or-evidence-record.md`
   The captured evidence and the current page-state summary.
4. `verification-report.md`
   The checks that confirm the page is in the intended pre-submit state.
5. `approval-record.md`
   The human gate before the irreversible submit action.
6. `failure-review.md`
   The plausible page-state failure and the controls that should catch it.

This bundle is meant to show why web agents need state verification and approval before high-impact submissions.

Treat these files as examples of the records a serious web agent should emit or be able to reconstruct, not as extra commentary around the case.
