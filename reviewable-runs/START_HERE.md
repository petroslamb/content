# Start Here

This package is most useful when treated as a run-level framework, not as a side note to the blueprint package.

## Fastest Useful Path

If you only read five things, read these:

1. `README.md`
2. `ORIGIN_AND_GAP.md`
3. `reviewable-runs.md`
4. `dossiers/README.md`
5. `evaluation/run-review-checklist.md`

## If You Are Testing The Core Claim

Read `ORIGIN_AND_GAP.md`, then `reviewable-runs.md`, then `MATURITY_AND_VALIDATION.md`.

This path answers:

- why this package exists
- what gap it fills
- what it claims
- what remains unproven

## Orientation Rule

The direct center of this package is the six review questions.

- `reviewable-runs.md` defines them.
- `dossiers/` shows them answered.
- `evaluation/run-review-checklist.md` reviews a run against them.
- `templates/` gives you the record formats that answer them.

Everything else is support.
