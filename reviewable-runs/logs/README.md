# Logs

This folder is the lightweight operational record layer for Reviewable Runs.

Use it for:

- routine bounded internal runs
- autogenerated lifecycle-stage logs
- low-ceremony records that are useful operationally but do not justify proof retention

Do not treat everything here as a proof artifact. The default path is:

1. log the run here
2. keep the boundary and verification legible
3. promote only the rare runs that add real public or governance value into [`../examples/proofs/`](../examples/proofs/README.md)

Typical examples:

- `run_stage.py` lifecycle records
- harness launch packs emitted by `stage:resolve --emit-launch-pack`
- lightweight manual-gate outcomes
- small operational notes that preserve what happened without reconstructing a full packet
- [`legacy-stage-runs/`](legacy-stage-runs/README.md) for older autogenerated stage packets retained as operational history after the proof/log split was cleaned up

If a logged run later needs stronger review, use [`../PLAYBOOK.md`](../PLAYBOOK.md) to decide whether it should stay lightweight, gain a fuller packet, or be promoted into the retained proof set.

## Minimum Schema

New lifecycle logs and harness launch packs should use `schema_version: 2`.

The minimum v2 surface must make the six review questions answerable without opening a full proof packet:

- task boundary: `task.objective`, `task.stop_condition`, and explicit non-goals
- action trace: `execution.commands`, output excerpt, and before/after state for lifecycle logs
- evidence surface: workflow doc, status path, required context, expected outputs, and done criteria
- verification: named checks plus residual risk
- approval and boundary: boundary type, approval gate, approval status, and whether any external side effect happened
- failure/risk: actual failure when present plus plausible failure modes

Validate this layer with:

```bash
npm run check:reviewable-runs
```

Older JSON logs without `schema_version` are grandfathered as legacy operational records. Do not use them as examples for new runs.
