# Legacy Stage Runs

This folder keeps the early autogenerated lifecycle-stage packets that were originally written into `examples/proofs/`.

They are retained as historical operational records, not as curated proof artifacts.

Why they live here now:

- they were routine stage records rather than selectively promoted proof cases
- their structure reflects an older runner shape
- some of them capture umbrella-level package names from before the leaf-first pilot settled

Use them only as lightweight operational history. For the retained proof set, use [`../../examples/proofs/`](../../examples/proofs/README.md).
