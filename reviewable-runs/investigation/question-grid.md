# Question Grid

Every lens memo in this folder answers the same fixed question set.

1. What kinds of runs does the framework handle best?
2. What kinds of runs resist it or become ambiguous?
3. Where does the framework add clear value beyond raw traces?
4. Where is it currently overbuilt or too manual?
5. Which parts of the framework are already coherent?
6. Which parts are underspecified, misaligned, or misleading?
7. What tuning is needed for usage policy, evaluation, and templates?
8. What implementation support would reduce manual overhead the most?
9. What claims are supported by real proof, and which still rely on synthetic support or inference?
10. What are the highest-value next experiments or corrections?

The point of the lens pass is not free-form reaction. It is to force the same evidence through several distinct judgment styles.
