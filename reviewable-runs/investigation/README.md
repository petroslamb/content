# Investigation

This folder is the advanced findings layer for Reviewable Runs.

It is for framework builders, not first-time readers.

Its job is to distill what the framework learned from:

- real proof packets
- secondary real traces
- synthetic validation
- the current operator, evaluation, and template surfaces

## What This Surface Does

This is where the package asks harder questions:

- what worked in practice
- what failed or stayed ambiguous
- where the framework is coherent already
- where it is underspecified or miscalibrated
- what tuning is needed
- what implementation support would make it materially lighter and stronger

## Folder Map

- `evidence-map.md`: the source-of-truth corpus for the investigation
- `question-grid.md`: the fixed question set every lens uses
- `lenses/`: explicit multi-hat judgment passes
- `synthesis/`: distilled findings, judgment, and next actions

## Reading Order

Read in this order:

1. `evidence-map.md`
2. `question-grid.md`
3. one or two lens memos
4. `synthesis/usage-findings.md`
5. `synthesis/framework-gaps-and-tuning.md`
6. `synthesis/results-and-judgment.md`
7. `synthesis/next-actions.md`

## Status

This is an advanced investigation surface.

- it is not part of the default front-door reading path
- it is not the teaching layer
- it is not proof by itself
- it is the package's explicit interpretation and tuning layer
