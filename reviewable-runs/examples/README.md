# Examples

This folder shows what Reviewable Runs looks like in practice.

It is split into two surfaces on purpose:

- `proofs/`: real evidence artifacts
- `teaching/`: synthetic teaching examples

## How To Read This Folder

If you want the strongest current evidence, start with:

1. `proofs/coding-real-run/README.md`
2. `proofs/coding-real-run/comparison.md`

If you want clean teaching examples, start with:

1. `teaching/README.md`
2. `teaching/comparison-matrix.md`
3. the closest teaching dossier

## Status Labels

This package uses three status labels:

- `real captured run`: preserved from a real run
- `synthetic teaching dossier`: designed to teach the framework shape clearly
- `hybrid`: mixes real and synthetic material

Current state:

- the canonical examples in `teaching/` are `synthetic teaching dossier`
- the coding proof in `proofs/coding-real-run/` is `real captured run`

## What This Folder Is For

- `proofs/` answers: does the framework help on a real run
- `teaching/` answers: what does a clean reviewable run look like

If you want to pressure-test the framework itself, use `../validation-lab/README.md`.
If you want historical lineage, use `../archive/artifact-bundles-v1/README.md`.
