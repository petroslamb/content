# Agent Revolution

Research corpus for *The Orchestration Paradigm* series on Substack and the broader agent stack coverage published in late 2025.

This folder contains working drafts, framework analysis, deep research notes, and production assets related to AI agent architectures, tool orchestration, and multi-agent coordination patterns.

## Contents

- `ToolOrchestra.md` — Deep-dive research on the ToolOrchestra paper (synthetic data pipelines, GRPO optimization, RL infra)
- `ToolOrchestra_Parts/` — Structured article drafts for the four-part Orchestration Paradigm series
- `Agent Stack - *.md` — Framework analysis documents covering abstraction layers and tooling options
- `The Agent Revolution.md` — Original research and drafts for the agent revolution publication
- `assets/` — Video overviews, thumbnails, and visual assets

## Published Articles

The research in this folder contributed to the *Orchestration Paradigm* series (Issues 1–4), published December 2025 on [Rooted Layers](https://lambpetros.substack.com).
