# Safety Essay and Materials

This folder contains the safety materials for the *Operating Agents* series:

- `05-safety-v7.md` - current public essay
- `05-safety-v6.md` - archived `v6` public baseline
- `companion-v7.md` - current second-pass companion essay
- earlier drafts remain for reference
- `artifacts/` - transcripts, slides, and video from the presentation

Read the public essay first, then the [current companion essay](companion-v7.md), then the matching blueprint, then the paper notes. The companion is meant to stand as a substantial second-pass read, not a short appendix.

The public title uses publication-order Roman numbering. The filename keeps `05` for repo continuity. For builder-facing defaults, start with the matching blueprint at `../../core/practical-chapter-blueprints/06-safety-blueprint.md`.
