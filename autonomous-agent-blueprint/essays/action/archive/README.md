# Action Essay and Materials

This folder contains the action materials for the *Operating Agents* series:

- `01-action-tool-use-v7.md` - current public essay
- `01-action-tool-use-v6.md` - archived `v6` public baseline
- `companion-v7.md` - current second-pass companion essay

Read the public essay first, then the [current companion essay](companion-v7.md), then the matching blueprint, then the paper notes. The companion is meant to stand as a substantial second-pass read, not a short appendix.

The public title uses publication-order Roman numbering. The filename keeps `01` for repo continuity. For builder-facing defaults, start with the matching blueprint at `../../core/practical-chapter-blueprints/03-action-tool-use-blueprint.md`.
