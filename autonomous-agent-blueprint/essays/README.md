# Essays: Operating Agents

This folder contains the public *Operating Agents* essay package. Each topic folder keeps the live essay, its companion, its local README, and any presentation artifacts together.

## Folder Map

- `launch-note/` - series framing
- `action/` - Operating Agents I
- `reasoning/` - Operating Agents II
- `memory/` - Operating Agents III
- `multi-agent/` - Operating Agents IV
- `safety/` - Operating Agents V
- `optimization/` - bonus post
- `operating-agents-coverage-map.md` - bridge from essays to blueprints, source notes, and the wider survey

## What Lives In A Topic Folder

Each topic folder contains:

- the current `v4` essay
- earlier drafts kept for reference
- `companion.md`
- `README.md`
- `artifacts/` when presentation material exists

The companion is intentionally local now. If you finish an essay and want the broader chapter, source, and omission map, open `companion.md` in the same folder.
