# Launch Note and Materials

This folder contains the Operating Agents series launch note:

- `00-launch-note-v8.md` - current launch and framing document
- `operating-agents-coverage-map-v7.md` - breadth-layer routing note for the essay package
- `00-launch-note-v6.md` - archived `v6` baseline
- `artifacts/` - transcripts, slides, and video from the presentation (if any)

The launch note explains the series' philosophy, reading order, and how the public essays relate to the deeper blueprint stack.

No companion essay exists for the launch note. The companion layer begins with the six numbered topic essays, and the breadth layer for this archived framing set sits in `./operating-agents-coverage-map-v7.md`.

If you are following the essay package, start here and then proceed to Parts I through VI in the reading order in `../README.md`. If you are building an agent, use the root `README.md` for the builder path.
