# Use Cases

This folder contains abstract reference architectures for common agent classes.

These docs are the implementation layer's design surface. They compose the chapter defaults from `../../core/practical-chapter-blueprints/` into bounded systems with explicit memory, reasoning, action, verification, and approval logic.

- `enterprise-agent.md`
- `coding-agent.md`
- `web-agent.md`

Read a use case after the matching blueprint when you want to see how several chapter defaults combine into one bounded system design.
