# Autonomous Agent Blueprint

This package organizes a local research corpus on foundation agents into a practical architecture guide and a set of chapter-specific blueprints.

## Entry Points

- `foundation-agents-practical-chapters-guide.md`: maps the source survey into the practical chapter structure.
- `agentic-architectures-blueprint.md`: synthesizes the main agent architecture patterns and their tradeoffs.
- `practical-chapter-blueprints/`: contains one analytic blueprint per practical chapter.
- `papers/`: contains local markdown notes for the supporting literature.

## Local Corpus

Raw PDFs are kept locally for reference but ignored by git in this package. The tracked source of truth is the markdown material.
