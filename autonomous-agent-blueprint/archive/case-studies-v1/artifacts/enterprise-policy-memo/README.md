# Artifact Guide: Enterprise Policy Memo

Read these files in order:

1. `input-brief.md`
   What the agent was asked to produce and the constraints it had to obey.
2. `planner-trace.md`
   The intended control loop for gathering evidence and drafting the memo.
3. `state-or-evidence-record.md`
   The retrieved grounding and the current working state.
4. `verification-report.md`
   The checks that turn the draft into a reviewable artifact.
5. `approval-record.md`
   The human gate that controls publication.
6. `failure-review.md`
   The plausible failure and the repo controls that should catch it.

This bundle is meant to show one clean enterprise good path plus one governance-focused failure.

Treat these files as examples of the records a serious enterprise agent should emit or be able to reconstruct, not as extra commentary around the case.
