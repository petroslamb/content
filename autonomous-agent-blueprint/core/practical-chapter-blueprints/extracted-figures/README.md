# Extracted Figures

This folder is the structured figure layer for the practical chapter blueprints and the public companion chapters. Files are grouped by topic so a writer can find the right chapter asset without remembering the original screenshot timestamp or PDF page.

The canonical naming rules are:

- booklet figures: `<topic>-fig-<chapter>.<figure>-<slug>.png`
- booklet tables: `<topic>-table-<chapter>.<table>-<slug>.png`
- course slide derivatives used to fill thin chapters: `<topic>-slide-<slug>.png`

The booklet source for numbered figures and tables is [`../../advances-and-challenges-in-foundation-agents.pdf`](/Users/petros/Projects/content/autonomous-agent-blueprint/advances-and-challenges-in-foundation-agents.pdf). When a file was created from a full page render rather than a tight crop, the filename still points to the figure number it preserves.
