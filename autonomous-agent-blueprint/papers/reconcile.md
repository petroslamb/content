# RECONCILE: Round-Table Conference Improves Reasoning via Consensus among Diverse LLMs

- Year: 2023
- Primary chapter: Multi-Agent Design
- Method category: consensus reasoning
- Practical role: structured disagreement and reconciliation reference
- Key contribution: Makes multi-agent disagreement more structured and confidence-aware.
- Major limitation: More useful for reliability overlays than for default system design.
- Confidence: High
- Canonical link: https://arxiv.org/abs/2309.13007
