Single-publication package behind the published Rooted Layers essay *When the LLM Programs Its Own Thinking*. The package combines the public essay, the companion paper surface, supporting papers, visuals, and distribution variants.

## Papers, Artifacts, Archive, And Distribution

- Supporting papers live in [`papers/`](papers/).
- Converted paper markdown lives in [`papers/markdown/`](papers/markdown/).
- The package paper index lives in [`papers/index.md`](papers/index.md).
- Visual and slide artifacts live in [`visuals/`](visuals/) and [`artifacts/`](artifacts/).
- NotebookLM notebook mapping lives in [`status.yaml`](status.yaml) and is indexed in [`../notebooklm-notebooks.md`](../notebooklm-notebooks.md).
- Retired or superseded package material belongs in [`archive/`](archive/).
- Platform-specific distribution variants remain at the package root because they are part of the publication surface.

## Working Guidance

- Treat [`when-the-llm-programs-its-own-thinking.md`](when-the-llm-programs-its-own-thinking.md) as the canonical published essay.
- Treat [`rlm-jupyter-integration.md`](rlm-jupyter-integration.md) as an earlier working source whose small code and formatting differences do not override the published snapshot.
- Treat the distribution variants as channel-specific derivatives, not as competing live drafts.
- If another major revision cycle happens, keep the live essay stable and move superseded working variants into [`archive/`](archive/).
