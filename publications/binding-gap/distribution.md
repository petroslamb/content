## Sync Policy

- **Substack -> YouTube Podcast**: Initial sync is handled by Substack's native YouTube distribution feature.
- **Description Updates**: Metadata updates (like adding the Reddit thread) are managed **locally in the repo** and pushed to YouTube via the `youtube-data-api` skill. Changes do NOT sync back to Substack.
- **Graphic Assets**: Slide deck updates only apply to the **Visual Deep Dive** version. The Podcast version remains static after launch.
