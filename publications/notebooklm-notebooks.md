# NotebookLM Notebook Registry

This is the human-readable index of NotebookLM notebooks tied to Rooted Layers publication packages.

The machine-readable source of truth lives in each package or leaf `status.yaml` under `config.notebooklm_*`, `config.notebooklm_related_notebooks`, or `config.notebooklm_posts`. Links are restricted owner NotebookLM URLs. They do not imply public access, and this repo should not track `.notebooklm/` browser state or hidden auth storage.
