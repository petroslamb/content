# NotebookLM Notebook Registry

This is the human-readable index of NotebookLM notebooks tied to Rooted Layers publication packages.

The public source of truth stores only notebook titles in package or leaf `status.yaml` under `config.notebooklm_*`, `config.notebooklm_related_notebooks`, or `config.notebooklm_posts`. Restricted owner NotebookLM IDs and URLs live in the ignored private overlay at `CONTENT_PRIVATE_DIR/notebooklm_registry.yaml` (default `.private/notebooklm_registry.yaml`). This repo should not track `.notebooklm/` browser state, hidden auth storage, or restricted NotebookLM URLs.
