# Validation Is Lifecycle Infrastructure

Status: narrowed doctrine brief, not a flagship replacement draft.

## Core Claim

Once workflow specs, policy surfaces, and evidence indexes start governing agent behavior, validation stops being terminal QA. It becomes the lifecycle infrastructure that keeps those source-like surfaces attached to reality.

## False Proxy

The false proxy is the belief that validation mainly happens at the end:

- test the output
- inspect the trace
- debug the runtime

That frame arrives too late. By then the workflow layer may already have drifted away from the constraints, policy, or evidence it was supposed to obey.

## Public Enemy

The sharper enemy is the advisory-prose illusion around governed workflow surfaces.

Operators keep treating workflow docs, policy files, and evidence maps like commentary because they remain human-readable. Meanwhile validators, policy checks, and traces are already depending on those files as real control surfaces.

## Doctrine Boundary

This object is narrower than the original flagship attempt.

It does not need to prove that markdown itself is becoming a general programming substrate. It only needs to prove a tighter doctrine:

- source-like workflow surfaces become governable only when validation spans the whole lifecycle
- traces matter because they can be checked against declared source and policy
- provenance matters because promoted claims need more than post-hoc runtime explanation

## Load-Bearing Evidence

The strongest package-backed supports are:

- `ContextCov` for instruction-level constraint enforcement
- `AgentFixer` for multi-stage diagnosis, cross-stage checks, and refinement loops
- `ALARA` and `Progent` for policy-backed control surfaces and least-privilege enforcement
- `FASTRIC` and `AgentPex` for prompt-protocol conformance and trace checking
- `Claim-Level Auditability` for why trace is not enough once claims must remain auditable
- the local `spec-diff` proof for a bounded, package-native drift example

## What This Object Must Not Do

- It must not collapse back into a full source / validation / trace / provenance stack tour.
- It must not rely on "You're Debugging The Wrong Layer" as the thesis instead of the wrapper.
- It must not pretend it clears the original north-star flagship bar.
- It must not reopen broad pivot search inside the same draft.

## Next Writing Rule

Treat this as a strong narrower doctrine write.

The next drafting pass should stay inside one bounded public claim:

Validation is the infrastructure that makes workflow specifications, policy surfaces, and evidence maps governable objects rather than advisory prose.
