## Thesis Boundary

The successor object is not `natural language is code`.

The defensible object is:

controlled, maintained, typed, linted, validated, or trace-linked specification surfaces becoming source-of-truth artifacts in AI-native development.

The public enemy is `vibe`: treating intent as informal prompt material while generated code remains the only artifact worth governing.

The governing term is `specification surface`.
