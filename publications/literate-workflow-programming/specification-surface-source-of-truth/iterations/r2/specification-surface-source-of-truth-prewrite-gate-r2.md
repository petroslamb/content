## Promise

Authorize one bounded r2 candidate for `The Specification Surface Is the New Source of Truth`. The essay promise is that AI-assisted software work increasingly moves durable authority into maintained specification surfaces when those surfaces constrain, coordinate, validate, test, trace, or authorize generated implementation. The candidate may use `vibe` as the public enemy only when it names the source-of-truth failure: intent remains informal while generated code becomes the only artifact treated as serious.

## Spine

1. Open on a professional review failure where the diff is visible but the governing intent artifact is missing.
2. Define `specification surface` and exclude loose prose, one-off prompts, stale design docs, and ordinary README text unless they enter a control or review path.
3. Use spec-driven development as the general software bridge from code-centric work to specifications as authoritative contracts.
4. Use the specification-gap paper to show underspecification as coordination failure and full specification as the strongest recovery instrument.
5. Use the professional-control paper to turn anti-vibe into observed practice: planning, supervision, validation, version control, and expertise.
6. Compress the r1 source/runtime/validation stack into the mechanism that makes surfaces operational.
7. Preserve the context-file caveat and close with an operator doctrine for maintaining governed surfaces.
