## Promise

Authorize one bounded candidate for `The Specification Surface Is the New Source of Truth`. The essay promise is that AI-native software work increasingly puts durable authority in governed specification surfaces rather than in loose prompts or generated implementation alone. The authorized claim depends on the maintained, controlled, validated, typed, linted, trace-linked, or runtime-interpreted surface qualifier.

## Spine

1. Open on the source-of-truth failure created by vibe practice.
2. Define `specification surface` and exclude loose prose, ordinary README text, and one-off prompts.
3. Build the evidence stack from specification-as-program, harness, executable-constraint, test-definition, validation, and trace-audit papers.
4. Add bridge evidence from context files, controlled natural language, and professional-control papers with the required caveats.
5. State the doctrine: generated code, tests, traces, and logs matter, but they are governed downstream of the maintained specification surface.
6. End with the operator burden for teams using AI-assisted software work.

## Paragraph burden

Each paragraph must either sharpen the governing term, add an evidence-backed mechanism, enforce a boundary, or translate the claim into operator doctrine. A paragraph that only restates the thesis, inflates the stakes, or lists papers without changing the reader's model should be cut.

## Evidence burden

The candidate may use the local shared paper index for body evidence on specification-as-program, natural-language harnesses, agent specification languages, executable instruction constraints, test-driven agent definitions, prompt specification, trace compliance, validation loops, and claim-level auditability. It may use the non-agent bridge papers as named pressure or synthesis support, but close reading and direct quotations from those papers require targeted intake before promotion. Context-file evidence must stay metric-specific and must carry the negative AGENTS.md caveat.

## Cut order

Cut donor-history exposition first, then local repo tooling detail, then optional skills and externalization material, then extra context-file survey material. Preserve the definition, the evidence stack, the forbidden-claim boundary, and the operator doctrine.

## Failure triggers

Void the draft pass if it claims natural language is code, treats passive prose as source of truth, says generated code no longer matters, turns into a context-file booster essay, uses the non-agent bridge papers for quotation-heavy argument without intake, or drops the controlled/maintained/validated surface qualifier from the largest claim.
