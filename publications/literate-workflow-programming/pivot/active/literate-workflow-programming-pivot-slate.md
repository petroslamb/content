# Reopened Pivot Slate

## Reopen Reason

The previous `no_successor` closure blocked `The Real System Lives In The Contract Layer` because the phrase and consequence surface stayed too inward: strong governed-agent doctrine, weak public object.

The reopened search starts from a different candidate family. It does not try to rescue `contract layer`. It asks whether the larger object is the migration of source-of-truth authority into constrained specification surfaces.

## Candidate Families

### 1. The Specification Surface Is the New Source of Truth

- Object type: successor flagship candidate
- Promise: AI-native work is not moving from code to vibes. It is moving from code-first review to specification-first control surfaces.
- Reused assets: specification-as-source evidence, natural-language outlines, agent harness specs, context-file contradiction state, local `spec-diff` proof.
- Evidence delta: needs the new spec-driven development, specification-gap, professional-control, shared prompt/program state, and controlled-natural-language papers inspected before clearance.
- Why it could break the ceiling: it gives the package a more portable public enemy than `contract layer`: treating operational specifications as mere prompts, docs, or vibe descriptions.
- Kill criteria: fails if the article says loose prose is becoming code, or if the evidence only supports agent-specific workflow files.
- Compact score: debate gain high; aperture gain high; doctrine utility high; opening power high; synthesis headroom high.

### 2. Professionals Don't Vibe, They Control

- Object type: wrapper rival
- Promise: the public enemy is vibe coding as a false proxy for AI-native software practice.
- Reused assets: `Professional Software Developers Don't Vibe, They Control`, `VibeContract`, `Spec-Driven Development`, AGENTS.md negative evidence.
- Evidence delta: needs more professional practice evidence before it can outrank the specification-surface candidate.
- Why it could break the ceiling: strong public phrase and clear antagonist.
- Kill criteria: becomes a commentary essay about vibe coding instead of a package-specific successor.
- Compact score: debate gain high; aperture gain medium; doctrine utility medium; opening power high; synthesis headroom medium.

### 3. Context Files Are Living Configuration

- Object type: supporting seam
- Promise: AGENTS.md, Agent READMEs, and context files are evolving configuration artifacts, not static docs.
- Reused assets: local AGENTS.md policy, context-file evidence, `spec-diff`, contradiction register.
- Evidence delta: must reconcile positive context-file adoption with evidence that context files can reduce task success and raise cost.
- Why it could break the ceiling: brings the package from abstract workflow doctrine into the real repository artifacts people are now writing.
- Kill criteria: too narrow if it remains an AGENTS.md essay.
- Compact score: debate gain medium; aperture gain medium; doctrine utility high; opening power medium; synthesis headroom medium.

### 4. VibeContract: QA Moves Upstream Into the Spec

- Object type: QA/provenance seam
- Promise: when AI writes code from intent, quality assurance has to attach to the task contract before implementation exists.
- Reused assets: validation-as-lifecycle branch, trace/provenance evidence, VibeContract, specification-gap evidence.
- Evidence delta: needs stronger proof that this is more than a software QA doctrine branch.
- Why it could break the ceiling: gives the article a consequential operator move.
- Kill criteria: collapses back into the already rejected validation-doctrine branch.
- Compact score: debate gain medium; aperture gain medium; doctrine utility high; opening power medium; synthesis headroom medium.
