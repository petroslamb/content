## Public Enemy Rerank

The weak version of the candidate says:

- the docs matter more than people think

That is still too small and too advisory.

The stronger enemy visible across the package is:

- operators keep reading contract surfaces as commentary after those same surfaces have already become the place where authority, scope, and evidence discipline are being decided

That is a sharper enemy than terminal QA or "bad docs." It names a specific misreading:

- workflow specifications stay human-readable
- policy and validation systems start depending on them as governing artifacts
- people keep debugging the runtime after the real break has already happened upstream

So the live enemy is no longer merely `advisory prose`.
It is the runtime-first reflex that survives after governance has already moved into editable contract surfaces.

## Consequence Surface

### 1. Constraint drift becomes governance drift

`ContextCov`, `AgentSPEX`, and the local `spec-diff` proof all point at the same thing:

- constraints can stay text-shaped while still acting as the layer that determines what is in or out of scope

Once that is true, drift in the contract layer is not a documentation error. It is a governance error that later appears as a runtime symptom.

### 2. Authority boundaries move before anyone checks the runtime

`ALARA` and `Progent` matter here because permissions, least-privilege surfaces, and control boundaries are declared in policy-backed or file-backed forms before a single run succeeds or fails.

That enlarges the consequence beyond "validate sooner":

- operators can mislocate where authority is actually being assigned
- the runtime then looks like the failure site even though the failure was already baked into the governing layer

### 3. Cascading failures are symptoms of upstream contract breakage

`AgentFixer` helps the candidate because it makes late diagnosis itself part of the evidence.
The point is not only that multi-stage systems are hard to debug.
The point is that once the governing layer drifts, runtime-only diagnosis arrives after the workflow has already propagated the mistake through multiple stages.

### 4. Claim promotion outruns trace-only accountability

`Claim-Level Auditability` and the local claim-provenance note sharpen the downstream limit:

- traces can show what happened
- they cannot guarantee that the promoted claim stayed attached to the right evidence and rules after the governing layer drifted

That makes the consequence larger than "better observability."
It becomes a problem of unverifiable synthesis after contract-layer drift has already contaminated the claim path.

## Scale Check

This pass makes the candidate larger in one real way:

- it now spans workflow specification, policy-backed control, failure propagation, and claim-level auditability

So the candidate is no longer only a repo doctrine or validation doctrine note.

The remaining limit is still the same one that matters most:

- the package proves this strongly inside governed agent systems
- it still does not prove that the public consequence travels far outside that domain

The seam widened, but it did not break into a broader field-ordering claim.

## Pressure Test Against The Current Block

This pass changes three things:

1. the candidate now has a better enemy than `validation happens too late`
2. the consequence is now about mislocated authority and upstream governance drift, not only QA timing
3. the candidate now explains more cleanly why the wrong-layer wrapper survives as a symptom rather than as the thesis

But the pass does not change the decisive blocker:

- the candidate still lands as a strong agent-governance doctrine argument before it lands as a larger flagship reorder

## Verdict

`The Real System Lives In The Contract Layer` is stronger after this pass, but it remains north-star blocked.

The package now has a clearer reason to keep it above the doctrine branch and above the wrapper rival.
It still does not have enough scale, public language, or field-spanning consequence to justify a new flagship successor leaf.
