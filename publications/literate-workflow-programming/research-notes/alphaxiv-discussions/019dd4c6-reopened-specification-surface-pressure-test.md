## Adopted

The reopened package should not use a loose `natural language is infrastructure` thesis.

Adopt this narrower candidate:

`The Specification Surface Is the New Source of Truth`

The useful governing term is `specification surface`, not `contract layer`.

The useful public enemy is `vibe`: treating intent as an informal prompt and generated code as the only artifact worth governing.

## Rejected

Reject the broad version:

`natural language is becoming code`

The evidence does not support that. The strongest success cases use constrained, maintained, typed, linted, validated, or traceable specification surfaces. The negative AGENTS.md evidence also shows that more context is not automatically better.
