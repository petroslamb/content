# Claims

Shared claim-state surfaces for the `literate-workflow-programming` umbrella.

Use this folder for package-wide claim permission, contradiction tracking, scoring, and provenance records that can be reused by the donor leaf, successor leaf, and historical branches.

- [`claim-ledger.md`](claim-ledger.md): candidate claims and evidence state.
- [`contradiction-register.md`](contradiction-register.md): caveats, alternate readings, and authority tensions.
- [`claim-scoring-rubric.md`](claim-scoring-rubric.md): scoring rules for article and proof readiness.
- [`claim-scorecard.md`](claim-scorecard.md): current top-claim draft gate.
- [`claim-provenance-manifest-r1.json`](claim-provenance-manifest-r1.json): machine-readable claim provenance manifest.
