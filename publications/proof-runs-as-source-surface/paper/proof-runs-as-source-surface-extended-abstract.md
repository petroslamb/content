# Extended Abstract

Autonomous content agents can now initialize publication packages, transform
drafts, coordinate research evidence, and prepare downstream artifacts. The
central trust question is no longer whether a model can produce plausible prose.
It is what evidence must exist before a human should trust the agent to mutate,
resume, or prepare a package for publication.

This paper proposes `proof runs as source surfaces`: retained governed run
records that bind workflow declarations, admitted context, source hashes,
allowed tools, path boundaries, review gates, subagent handoffs, validation
commands, and local outputs into an inspectable artifact. The framework separates
three concerns that are often conflated: capability evidence, execution
authority, and publication trust.

The planned contribution is a framework and systematization for governed
content-agent work. The paper maps related evidence from specification-driven
agents, context-grounded workflows, benchmark studies, governance papers,
schema-gated scientific workflows, and specification-anchored audit pipelines.
It then outlines an illustrative artifact analysis of one retained proof-campaign
run, coding artifacts for workflow identity, context admission, boundary
discipline, handoff integrity, blocker visibility, external mutation,
lifecycle movement, and promotion boundaries.

The paper does not claim that agents can publish themselves safely, that
benchmark scores are sufficient for trust, or that one local proof run proves
external validity. Its narrower claim is that governed proof runs can become the
reviewable source surface for deciding whether autonomous content work may be
trusted, resumed, hardened, or stopped.
