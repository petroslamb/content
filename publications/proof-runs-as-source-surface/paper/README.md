# Proof Runs As Source Surface Paper Route

This folder contains local academic-paper artifacts for the experimental
`paper_development` workflow.

The route is separate from the live essay path. Files here may harden an
academic contribution, method, evidence map, or venue-facing packet, but they do
not promote the live draft, move package lifecycle state, submit externally, or
claim workflow promotion.

## Source Package

- package: `proof-runs-as-source-surface`
- live draft: `../proof-runs-as-source-surface.md`
- package status: `../status.yaml`
- evidence surface: `../papers/index.md`

## Paper Question

What evidence must a governed local runtime emit before a human should trust an
agent to initialize, mutate, resume, or publish a content package?

## Working Boundary

The paper route should test whether the essay argument can become a scholarly
contribution by adding at least one concrete contribution surface:

- definition of proof runs as source surfaces
- lifecycle or process model for governed content-agent work
- systematization table for evidence emitted by local autonomous workflows
- illustrative artifact analysis using retained Reviewable Runs records

## Local Outputs

Expected paper-development artifacts live in this folder:

- paper roadmap
- north-star rubric
- paper blueprint
- publication route note when a venue or preprint route is under consideration
- literature mapping table
- case-study trace plan
- extended abstract only after the blueprint and method path are concrete
- draftability audit before any full manuscript drafting
- docs-only two-reviewer approval gate before manuscript drafting

## Stop Rules

Stop before manuscript drafting if the route remains essay-shaped, lacks a
case-study unit or artifact corpus, lacks a literature/evidence map, violates
the package claim boundaries, or treats arXiv as peer review.
