# Proof Runs As Source Surface Paper Roadmap

## Current Phase

Route setup and draftability proof. This run is creating local paper-route
artifacts for the experimental `paper_development` workflow. It does not move
package status, publish, submit, or promote the workflow.

## Source Argument

The package argument is that governed proof runs are the trustworthy surface for
autonomous content work because they bind declared workflows, admitted context,
bounded tools, gates, and retained evidence into a reviewable record.

## Paper Route Hypothesis

The paper is viable only if it becomes more than an essay. The minimum academic
shape is a framework and systematization paper with an illustrative artifact
analysis of retained Reviewable Runs evidence.

## Next Decision

Proceed through rubric, blueprint, literature mapping, case-study trace, extended
abstract, and draftability audit. Stop at the docs-only approval gate if the
audit recommends drafting. If the audit finds the method too thin, stop before
manuscript drafting and mark the next action as method hardening.

## Parking Policy

Park the paper route if the contribution remains essay-shaped, if the evidence
map cannot carry a scholarly burden, if no artifact corpus can be named, if
forbidden claims are needed to make the paper sound strong, or if the route
treats arXiv as peer review.

## Proof Boundary

This roadmap is retained proof evidence for the experimental workflow run. It is
not a workflow-promotion note and not a publication-readiness claim.
