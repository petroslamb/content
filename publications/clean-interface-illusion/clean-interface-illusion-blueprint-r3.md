## Promise

This pass will keep the same thesis and remove the remaining explanatory drag. The essay should now argue, as directly as possible, that richer agent benchmarks already exist and that the live error is interpretive overreach: flattening reliability-relevant evaluation structure back into one readiness signal. The ending must tie that doctrine to deployment review, routing, and fallback decisions.

   Use the `tau-bench` repeated-run collapse as the public scene.
2. **Immediate dispute**
   Retire the toy-benchmark objection quickly, with minimal name load.
3. **Reliability object**
   Explain why capability scores and operational trust diverge.
4. **Comparative middle**
   Read `WebSuite` and `WebForge` together as one argument about richer decision surfaces.
5. **Delegation boundary**
   Use `LiveMCPBench` and `TheAgentCompany`, with `REAL` compressed, to show bounded usefulness without broad trust.
