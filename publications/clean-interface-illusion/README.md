## Current Frame

The active thesis line is narrower than a generic "benchmarks are bad" complaint:

- current agent benchmarks increasingly include realistic stressors
- the real editorial claim is that point success rates remain badly calibrated to deployment trust because reliability, recovery, and perturbation behavior lag capability
