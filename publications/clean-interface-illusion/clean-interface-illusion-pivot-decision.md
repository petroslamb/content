# Pivot Decision

## Decision

Open the new flagship pivot when ready.

`Capability Is Not Delegation` is now blocked by the research-grounding gate.
`From Accuracy to Readiness` has been overtaken.
`Corrective Competence / Capability-Comprehension Gap` cleared after the final full-package synthesis pass.

The current cleared pivot candidate is `Corrective Competence / Capability-Comprehension Gap`.
The strongest adjacent workflow seam is `Contestability-Preserving Workflow Design`.

## Why This Wins

The initial slate favored `Capability Is Not Delegation` because it was the best upward expansion from the capped donor essay.

It keeps what already works:

- a vivid opening anomaly
- a strong benchmark-to-trust critique
- clear operator consequence

It also opens a larger field question:

- when is a system merely capable
- when is a task actually delegable
- what evidence makes that difference legible

That is a bigger public object than benchmark interpretation alone.

The grounded alphaXiv pass eventually crossed the threshold. The seam now looks strong enough to justify a real flagship pivot, not only continued candidate hunting.

## Why The Other Candidates Lost

### The Delegability Gap

This is the strongest internal concept, but not the best standalone public object on its own. As a flagship headline it risks becoming too neat, coined, or inward before the surrounding evidence has earned the term.

### Evaluation Is Governance

This remains a strong doctrine seam, but the current evidence looks better at showing that evaluation shapes governance than at proving that evaluation itself is the core governance object.

### Split And Promote

This is still a valid package move if the new flagship attempt stalls. It is not the breakout argument itself.

### Appropriate Reliance / Agency Noise

The grounding pass surfaced two stronger research-backed alternatives than the original donor object:

- `Appropriate Reliance in Practice`
- `Agency Noise Signature`

Both look more supportable from the current seam than a delegability flagship. Neither has yet cleared the north-star grounding bar.

### Corrective Competence / Capability-Comprehension Gap

This candidate temporarily became the strongest conceptual winner because it identified the deeper structural failure mode: assisted performance can rise while independent oversight capacity deteriorates.

The threshold search exposed a real blocker around domain-calibrated anchors for preserved understanding, but a later comparative rerank, behavioral-proxy pass, and full-package synthesis pass restored it and then cleared it for a flagship attempt.

### Verification-Preserving Workflow Design

The later workflow pass elevated a stronger tractable seam:

- `Verification-Preserving Workflow Design`

That seam then refined into:

- `Contestability-Preserving Workflow Design`

It is now the strongest workflow-layer object because it retains the oversight problem while shifting the evidentiary burden from inferred internal competence thresholds to observable workflow structure.

It did not ultimately overtake corrective competence in the final comparative rerank.

## Research Decision

Open the new flagship package when ready.

## Gate For Package Split

Open a sibling flagship package only if a later research pass produces:

- a tighter thesis than the capped donor object
- at least one body-paper seam outside pure benchmark methodology
- a sharper downstream consequence than "read scores more carefully"
- evidence that links the proposed mechanism to consequential delegation outcomes rather than just descriptive correlations
- enough cross-domain grounding to treat corrective competence as more than a narrow warning, or enough integrated evidence to fuse it cleanly with contestability-preserving workflow design

If that gate fails, either publish `r3` as a strong non-flagship piece or reopen the topic under a different pivot.
