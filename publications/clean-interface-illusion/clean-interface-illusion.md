# The Clean Interface Illusion

## Working Thesis

Current agent benchmarks do not fail mainly because they are too clean. They fail when point success rates, even on increasingly realistic benchmarks, are treated as proxies for deployment trust despite high variance, brittle recovery, and weak reliability under perturbation.

## Essay Promise

This essay will argue that the field has improved benchmark realism faster than it has improved benchmark interpretation. More realistic agent evaluations now expose retrieval failures, policy failures, recovery failures, and privilege failures directly. The persistent mistake is reading a pass rate as if it already measured operational trust.

## Non-Claims

- This essay is not claiming that agent benchmarks are worthless.
- This essay is not claiming that current agents are useless in production.
- This essay is not claiming that aggregate scores should disappear altogether.

## Current Body Spine

1. The field already knows how to build harder agent benchmarks.
2. Those harder benchmarks still do not justify confidence if reliability is unstable across perturbations and reruns.
3. The right question is no longer "is the benchmark realistic?" but "what does this success rate actually license?"

## Current Blocker

The blueprint and local evidence surface still need to be hardened before a serious flagship draft can be written.
