## Core Thesis

AI assistance can raise visible performance while eroding the human capacity required for genuine oversight. The key variable is corrective competence: the ability to detect, explain, contest, and repair AI-assisted work without depending on the AI that produced it.

## Residual Risks To Carry Forward

### 1. Longitudinal professional competence loss

The strongest missing piece is still evidence that sustained AI use degrades independent competence over time in real professional settings.

The ideal evidence would track:

- professional users
- repeated AI use intensity
- independent task performance without AI
- error detection and repair ability
- changes across months rather than minutes or days

### 2. Domain generalization

The seam is strong in:

- programming
- education
- structured decision tasks
- safety engineering theory

It is weaker in:

- law
- medicine
- finance
- policy analysis
- creative or open-ended professional work

### 3. Verification boundary and workflow scope

The latest assistant pass surfaced a deeper blocker than simple domain coverage:

- some collaboration structures may outperform advisor-style verification by preserving independent judgment instead of asking humans to verify AI outputs
- some tasks may be poorly verifiable regardless of user competence

That means the candidate may govern a specific class of workflows:

- verification-dependent
- advisor-like
- responsibility-critical

rather than all human-AI collaboration.

The latest scope test then asked the narrower question directly:

- if the object is restricted to verification-dependent advisor workflows, does it clear?

Current answer:

- no

Why:

- task verifiability itself remains a limiting variable
- stronger human competence does not solve tasks that are structurally hard to verify
- the evidence still does not show that competence erosion is the decisive limiting factor across that bounded workflow class

The current refinement after the contestability pass is:

- corrective competence remains the main candidate
- contestability-preserving workflow design is the strongest adjacent seam explaining the workflow conditions under which competence can actually matter
### 4. Ontology consolidation

The seam still uses overlapping labels:

- epistemic debt
- agency gap
- metacognitive decoupling
- competence shadow
- capability-comprehension gap
- cognitive delegation

The next pass should determine whether one term can govern the others cleanly or whether the essay itself needs to supply that synthesis.

### 5. Boundary conditions against the calibration rival

The strongest rival frame is no longer a workflow replacement.

It is:

- `Appropriate Reliance Engineering`

The next pass needs to decide when the observed failures are:

- mostly interface and calibration failures
- versus genuine competence-loss dynamics that persist beyond better reliance design
