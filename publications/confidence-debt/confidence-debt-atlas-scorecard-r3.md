## Strongest Improvements Since R2

1. The ending now has a doctrine, not a slogan.
2. The evaluation section moved from benchmark interpretation to deployment release logic.
3. The human section now proposes software-mediated co-audit instead of relying on human vigilance.
4. The artifact section is no longer only the eip-verify pattern; it is backed by claim-auditability and provenance-interface work.
5. The essay now marks its own synthesis boundary rather than pretending the three-gate stack is already proven.

## Remaining Risks

1. **End-to-end proof gap.** The essay is honest about this, but it remains the highest ceiling. A single field case where an overconfident artifact, an over-read eval, and degraded review capacity interact would move this from 9.0 toward 9.3+.
2. **Middle density.** The claim-auditability, reliability, and co-audit sections each earn their place, but they still read partly like compressed research synthesis. A publication polish pass should remove any sentence that names a paper without changing the reader's operating model.
3. **Reference roughness.** Some references are title-only and need author/year cleanup before publication.
4. **Co-audit invention boundary.** The draft handles this responsibly, but readers may still ask whether the proposed workspace is too speculative. The best answer is to keep the exact workspace framed as an operating implication, not a validated product.

## North-Star Call

R3 is viable as the lead candidate. It has crossed from "interesting synthesis" into "usable doctrine." To move beyond a narrow 9, the next pass should be a polish pass, not another broad research pass: compress the middle, sharpen one rival-frame example, clean citations, and make the last doctrine land with more inevitability.
