# Confidence Debt

This live draft is intentionally blank. The package has a working thesis but the blueprint gates have not yet cleared.

Working thesis:

Confident AI output propagates faster than the evidence that should constrain it. That gap compounds across layers of the delegation stack. At the artifact layer, polished summaries outrank contradictory evidence. At the evaluation layer, aggregate scores outrank the reliability signals the benchmark actually measured. At the human layer, assisted output outruns the correction capacity the operator needs to intervene well. Each layer borrows confidence it has not earned. The debt compounds because downstream consumers inherit upstream overconfidence without seeing what was compressed away.
