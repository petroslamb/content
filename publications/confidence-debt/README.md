# Confidence Debt

Umbrella-style package for a north-star flagship attempt that fuses three capped donor leaves into one cross-layer thesis. ## Current Frame

The hypothesis: three independently capped essays share an unstated common argument. Each one shows that confident AI output outruns the evidence that should constrain it, but at a different layer of the delegation stack:

- **Artifact layer** (evidence-governance): polished summaries outrank row-level evidence
- **Evaluation layer** (clean-interface-illusion): aggregate scores outrank what the benchmark measured
- **Human layer** (corrective-competence): assisted output outruns retained correction capacity

The combined thesis claims these are not three independent problems but one structural failure at three altitudes, and that the compounding across layers is what makes it dangerous.

That claim is currently an editorial inference. It has not been structurally demonstrated yet. The thesis stress-test gate exists to test it before prose investment.
