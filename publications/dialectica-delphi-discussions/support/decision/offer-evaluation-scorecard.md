## Role Charter Draft

This is the concrete language to try to get into writing.

Petros will lead technical discovery and architecture for Dialectica Delphi as an expert-community operating system. Pere will own product/community direction. Michael or another named technical sponsor will define the technical evaluation bar and unblock engineering/system access. Compliance will own consent, retention, transcript reuse, anonymization, and client-facing approval boundaries.

The first milestone will not be a full member-facing platform. The first milestone will be a 30-45 day discovery and prototype phase that maps current systems, identifies the operating loop, defines the data model, reviews compliance constraints, and prototypes a thin operator workflow for one or more Delphi sessions.

The prototype should test whether Delphi compounds. Useful evidence includes repeat expert attendance, follow-up response rate, accepted introductions, recap usefulness, client pull for anonymized insight, operator time per artifact, and the quality of reviewed AI-assisted synthesis.

## First 45-Day Deliverables

The first phase should produce:

- current-system map
- expert journey map
- source-data inventory
- consent and compliance map
- draft expert/session/contribution data model
- build-versus-buy recommendation
- AI processing constraints and review workflow
- post-session operator workflow prototype
- success metrics and baseline measurement plan
