# Decision Reading Path

Start here when using this publication to decide whether to accept the proposed Delphi senior technical lead role.

## The Question This Package Should Answer

The decision is not "is Dialectica interesting?" or "is Pere's idea promising?" Both can be true while the offer is still badly scoped.

The decision question is:

Would this role give Petros enough access, authority, and sponsor alignment to turn Delphi into a technically grounded expert-community operating system before being asked to deliver a platform?

Everything in the package should be read against that question.

## What To Extract While Reading

Keep a short note with five columns:

- decision right
- owner
- evidence from the material
- question to ask
- red flag if unclear

The important decision rights are:

- product/community direction
- technical architecture
- data model
- AI processing and vendors
- transcript and chat reuse
- email/journey logic
- build-versus-buy
- compliance and consent
- release readiness
- success metrics

If a decision right has no owner, that is a negotiation point.

## Acceptance Test

The offer is worth serious consideration if the next conversations produce clear answers to four points:

- Pere owns product/community direction.
- Petros owns technical discovery and architecture.
- Michael or another named leader owns technical sponsorship and evaluation.
- Compliance owns consent, reuse, retention, and client-facing boundaries.

The offer should be slowed down if any of these remain vague:

- "platform" is the first milestone
- success means signups, events, or portal launch
- access to expert, CRM, email, transcript, or dbt data is unclear
- AI-generated summaries or profile enrichment have no review and consent model
- build-versus-buy decisions are already made before discovery
- Petros is accountable for strategic outcomes without decision rights

## The Current Best Position

The strongest stance to take into the conversations is:

"I am interested if the role is technical ownership of the Delphi operating loop, not just implementation of a platform. The first milestone should be discovery plus a thin operator workflow that proves whether the expert network compounds. Pere should own community direction, I should own technical architecture, Michael should clarify the technical bar, and compliance should own reuse and consent boundaries."
