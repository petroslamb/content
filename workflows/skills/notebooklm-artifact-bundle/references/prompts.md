# Prompt Map

Use these prompt files for the repo's default NotebookLM artifact voice:

- `./prompts/audio.txt`
- `./prompts/slide_deck.txt`
- `./prompts/video.txt`

## Voice Constraints

- Audio: calm research discussion, grounded in Rooted Layers framing, not hype.
- Slide deck: research-lab visual tone, minimal layouts, diagrams over stock imagery.
- Video: structural change, long-term implications, analytical tone instead of YouTube excitement.

Keep these defaults unless the user explicitly asks for a different framing.
