# Phase 2.1 — Executable Workflow Contract

## Goal

Make `workflow.yaml` the primary machine contract for the platform-targeted workflow set.

The runtime should no longer depend on README prose or scattered frontmatter to infer what a workflow may do.

## Deliverables

- one authored `workflow.yaml` beside each platform-targeted workflow README
- a stable minimal field set for ordered steps, required context, allowed tools, allowed paths, outputs, verification hooks, approval gates, and trace requirements
- drift checks between workflow README metadata and `workflow.yaml`
- a declared migration boundary from current workflow frontmatter to the new machine contract

## First Workflow Set

Start with the workflows that define the essay lifecycle and external publication path:

- `paper-intake`
- `alphaxiv-research`
- `essay-iteration`
- `article-polish`
- `substack-publishing`
- `substack-archive-sync`

Do not start by converting every workflow in the repo.

## Contract Decisions

- `workflow.yaml` is authored directly and checked for drift.
- The adjacent README remains the human explanation surface.
- The YAML owns machine authority for execution planning.
- README prose should not be asked to carry runtime permission semantics.

## Required Fields

Each `workflow.yaml` must define:

- `workflow_id`
- `version`
- `summary`
- `package_classes`
- `runner_mode`
- `required_context`
- `allowed_tools`
- `allowed_paths`
- `trace_requirements`
- `steps`

Each step must define:

- `id`
- `mode`
- `command` or named executor
- consumed inputs
- outputs
- verification hooks
- gate data when the step is gated

## Acceptance Read

2.1 is done when:

1. the target workflow set has authored `workflow.yaml` files
2. the field vocabulary is stable across that set
3. the machine contract is sufficient to plan execution without README parsing
4. drift checks exist and pass for the converted workflows

## Non-Goals

- no enforcement layer yet
- no gate runtime yet
- no dashboard work
- no full conversion of every workflow in the repo
