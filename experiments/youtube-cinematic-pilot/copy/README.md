# Pilot Copy

This folder owns the reusable copy surface for the cinematic pilot.

- `cinematic_prompt.txt`: NotebookLM generation prompt for `--format cinematic`
- `cinematic_description_template.md`: upload description template used by `scripts/upload_publication_cinematic.py`

These files are experiment-local on purpose. Do not move them into the shared NotebookLM default prompt bundle unless the cinematic lane graduates from experiment status.
