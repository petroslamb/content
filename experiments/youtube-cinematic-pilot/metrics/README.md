# Pilot Metrics

Store the pilot measurement outputs here.

Minimum checkpoint cadence for every upload:

- `+24h`
- `+72h`
- `+7d`

Each publication should end with:

- one per-upload metrics snapshot
- one publication summary
- one final experiment report covering keep/kill outcome and rollout recommendation

Manual Studio metrics to capture:

- impressions
- click-through rate
- average view duration
- 30-second retention
- traffic source mix
- subscribers gained

Repo/API metrics to capture:

- video ID
- public URL
- publish time
- playlist placement
- caption readiness time
- related-video write status
- likes
- comments
