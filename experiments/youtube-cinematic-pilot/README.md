# YouTube Cinematic Pilot

Bounded pilot state for the first cinematic companion-video wave.

Canonical process lives in [`../../workflows/youtube-cinematic-pilot/README.md`](../../workflows/youtube-cinematic-pilot/README.md). This folder keeps the cross-package pilot manifest, release calendar, copy templates, and metrics collected during the experiment.

## State Files

- `pilot_manifest.yaml`: pilot package/video plan
- `release_calendar.yaml`: planned or recorded release timing
- `copy/`: shared cinematic prompt and description templates
- `metrics/`: pilot and backfill run notes plus video/package crosswalks

## Boundary

This is an experiment state folder, not a publication package. Package-local source material and durable video artifacts should remain under the relevant `publications/` package.
