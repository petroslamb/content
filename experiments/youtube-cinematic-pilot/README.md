# YouTube Cinematic Pilot

Public orientation for the first cinematic companion-video wave.

Canonical process lives in [`../../workflows/youtube-cinematic-pilot/README.md`](../../workflows/youtube-cinematic-pilot/README.md). This folder keeps reusable public copy templates and a pointer to the workflow. Private pilot manifests, release timing, notes, metrics, upload reports, selected Shorts manifests, and channel readbacks live under `.private/youtube/cinematic-pilot/` and `.private/youtube/generated/` by default.

## State Files

- `copy/`: shared cinematic prompt and description templates
- `.private/youtube/cinematic-pilot/pilot_manifest.yaml`: private pilot package/video plan
- `.private/youtube/cinematic-pilot/release_calendar.yaml`: private planned or recorded release timing
- `.private/youtube/cinematic-pilot/metrics/`: private pilot and backfill run notes plus video/package crosswalks

## Boundary

This is an experiment orientation folder, not a publication package. Package-local source material and durable media artifacts should remain under the relevant `publications/` package. Channel-side operational state stays in the ignored private overlay.
