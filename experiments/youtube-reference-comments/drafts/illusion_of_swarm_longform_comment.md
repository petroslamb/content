This video leans most heavily on these sources:

- **When Single-Agent with Skills Replace Multi-Agent Systems and When They Fail** — the core evidence for the argument that many swarms can be compiled down into one agent plus a skill library.
- **Towards a Science of Scaling Agent Systems** — important because it replaces ideology with controlled comparisons across agent count, topology, capability, and task type.
- **Toward Efficient Agents: Memory, Tool Learning, and Planning** — helps frame the field-level convergence around memory control, planning efficiency, and tool routing.
- **ROMA** — shows where a structured multi-agent design genuinely earns its keep on long-horizon tasks.
- **SkillOrchestra** — useful because it ties orchestration to explicit competence and cost rather than to hand-wavy agent personas.

Full essay + full references: https://lambpetros.substack.com/p/the-illusion-of-the-swarm
