# YouTube Explainer Shorts

Historical metric surface for explainer Shorts experiments.

The operational YouTube process lives in [`../../workflows/youtube-channel-ops/README.md`](../../workflows/youtube-channel-ops/README.md). This folder preserves experiment metrics that do not belong to one publication package.

## State Files

- `metrics/`: run notes and results for explainer Shorts experiments

## Boundary

Keep only cross-package experiment records here. Package-specific Shorts manifests, captions, upload reports, and media should stay under the relevant package artifacts or the active rollout experiment folder.
